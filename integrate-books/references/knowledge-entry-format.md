# 知识点条目格式

阶段 1 知识提取时使用的条目模板。

## 知识库目录结构

```
.book-doc/knowledge_base/
├── INDEX/
│   ├── dsp_mapping.md   # 主书章节 → 知识点映射（阶段 2 产出）
│   ├── source_coverage.md # 各源书覆盖度统计
│   └── gaps.md          # 覆盖缺口清单
├── [源书1]/              # 各源书的知识点条目
├── [源书2]/
└── [源书3]/
```

## 条目格式

```markdown
---
id: [源书缩写]_[编号]
source: [源书全名]
chapter: [源书章节号和标题]
pages: [页码范围]
topics: [主题标签，逗号分隔]
importance: [core | supplementary | advanced]
verified: [V1 | V2 | V3 | V4]
---

## 核心内容
[200-500 字摘要]

## 关键洞察
[该知识点独有的、其他书可能没有的洞察]

## 代码示例
[关键代码片段。如果代码在目标版本不可运行，标注 ⚠ 并说明需要的版本]

## 教学价值
- 引入角度：[如何引入]
- 常见误解：[读者容易犯的错]
- 类比：[原文使用的类比]

## 依赖
- 前置概念：[需要先理解什么]
- 后续概念：[理解后能学什么]
```

## 字段说明

- `id`：全局唯一稳定 ID。`dsp_mapping.md` 必须逐条引用这些 ID，覆盖率脚本按 ID 计算映射覆盖率。
- `importance`：`core`（必须掌握）/ `supplementary`（加深理解）/ `advanced`（进阶内容）
- `verified`：代码提取自原书但未运行 → V4；已运行确认 → V1
- 提取节奏：每章 5-15 个知识点。判断标准：读者在未来的某个场景中会独立查找和引用这个知识吗？
