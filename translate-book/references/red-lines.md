# 翻译红线规则

不可违反的硬性约束，违反即视为翻译失败。

## 文本处理

- **逐段翻译，不可跳过**：每个段落都必须翻译，不可因"太简单""太技术"而跳过
- **不可合并段落**：原文几段就翻译几段，不可将多个段落合并为一段
- **不可拆分段落**：一个段落不可拆为多个，除非原文本身结构暗示（如列表项）
- **代码块原样保留**：代码块内的变量名、函数名、输出字符串、异常文本逐字复制。**代码注释翻译为中文**（`# This is a comment` → `# 这是注释`），但程序输出和 Python 报错文本保留英文不翻译
- **保留原文的强调结构**：加粗、斜体、行内代码标记必须对应翻译

## 术语处理

- **首次出现时括注英文**：如"装饰器（decorator）"，后续可直接用中文
- **约定术语统一**：同一英文术语全文统一译法，不可前文"迭代器"后文"迭代对象"
- **避免生造术语**：已有通用译法时不可自创新译，如 class 统一译"类"而非"类别"

## 格式处理

- **保留 HTML 标签结构**：翻译时保留原文的所有 HTML 标签和属性
- **保留锚点 ID**：`id="..."` 属性不可修改或删除
- **保留链接地址**：`href` 等属性值不可修改，但链接文字需翻译
- **图片 alt 属性需翻译**：`alt="..."` 中的描述文字翻译为中文
