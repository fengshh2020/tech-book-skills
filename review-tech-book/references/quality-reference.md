## 工程实践框架

核心问题：书中的代码和指导能否让读者在工作场景中可靠地使用这些技术？

### 五个子维度

| 子维度 | 检查要点 | 评分标准 |
|--------|----------|----------|
| 真实场景覆盖 | 示例模拟真实工作场景？错误处理和边界情况？常见变体？真实数据？ | 1=缺失 2=零散 3=有但偏玩具 4=良好 5=可直接应用 |
| 代码质量 | 符合社区最佳实践？命名有意义？无反模式？依赖管理合理？ | 同上 |
| 工具链整合 | 调试器/linter/formatter？测试写法？包管理和虚拟环境？CI/CD？ | 同上 |
| 调试与排错 | 调试策略？读错误信息？常见错误和解决方案？性能分析？ | 同上 |
| 生产就绪 | 部署考量？安全最佳实践？日志和监控？配置管理？ | 同上 |

## 经典教材方法论

从六本经典技术教材提取的教学设计方法，审阅时可参照判断"优秀实践"的标准。

### SICP — 抽象层次迁移

教学策略：在低抽象层次建立直觉→向高抽象层次迁移→展示两个层次间的映射。关键特征：延迟引入、渐近揭示、元循环评估器。

### How to Design Programs — 设计配方

教学策略：提供明确的"设计步骤"——从问题分析→合约→示例→模板→代码→测试。关键特征：问题→代码的确定路径、模板先于代码、测试先行。

### Python Crash Course — 项目驱动

教学策略：基础知识（短平快）→三个渐进项目。关键特征：知识密度低但节奏快、项目是读者真实想做的东西、项目间难度递进。

### Automate the Boring Stuff — 即时回报

教学策略：学一点立即用到真实任务。关键特征：零理论基础（直接做）、真实任务、最小知识原则。

### Eloquent JavaScript — 沉浸式叙事

教学策略：文本中嵌入可交互代码编辑器，叙事和代码完全交织。关键特征：每个概念配可运行示例、渐进式项目贯穿全书。

### Think Python — 科学家思维

教学策略：教"像计算机科学家一样思考"——分解、抽象、算法化。关键特征：调试优先于特性、逐步精化、强调"如何思考"。

## 在线资源对照

验证技术准确性和教学方法合理性时参考：

- **Python 官方文档**：docs.python.org — 最终权威
- **Real Python**：realpython.com — 高质量教程，教学设计标杆
- **Python Cookbook** (Beazley) — 实战模式参考
- **PEP 索引**：peps.python.org — 语言设计理由
- **Fluent Python (Ramalho)** — 深度 Python 教学标杆
- **Effective Python (Slatkin)** — 条目式最佳实践标杆
