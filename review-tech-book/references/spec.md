# 审阅规范：评分框架、输出模板、校验清单

阶段 1/3/4 读取。十六维度是**诊断工具**（识别具体问题）；五转化维度（见 `review-criteria.md`）是**整合评估**（判断对读者的整体效果）。任意技术栈通用。

## 十六维度评分框架

| 类 | # | 维度 | 核心问题 |
|---|---|---|---|
| **基础质量** | A1 | 技术准确性 | 目标版本下是否正确？（代码实机、API 核对、版本兼容） |
| | A2 | 覆盖度 | 核心主题是否全覆盖？（对照官方主题清单） |
| | A3 | 代码质量 | 示例是否健壮？（规范、边界、反模式） |
| | A4 | 时效性 | 是否反映当前最佳实践？（废弃 API、版本状态） |
| **阅读体验** | B1 | 可读性 | 能否顺畅阅读？（翻译腔、被动语态、长定语、节奏） |
| | B2 | 讲解深度 | 深度是否匹配目标读者？ |
| | B3 | 可视化 | 不可见过程是否图解？（调用栈/递归/作用域） |
| | B4 | 组织节奏 | 信息密度节奏合理？（高密→低密、概念→示例） |
| **教学设计** | C1 | 概念引入 | 概念如何首现？（动机先行 vs 定义先行、ELI5、类比） |
| | C2 | 类比系统 | 类比是否一致且正确？（是否说明失效处） |
| | C3 | 工程实践 | 能否在工作场景使用？（见 review-criteria 五子项） |
| **能力落地** | D1 | 实践迁移 | 能否迁移到真实任务？（项目化任务、变体场景） |
| | D2 | 反馈闭环 | 读者能否判断自己理解对否？（预期输出、检查点、反例） |
| | D3 | 调试能力 | 是否学会定位修复常见错误？ |
| | D4 | 检索能力 | 能否快速回查概念/API/示例？（索引、术语表、速查） |
| | D5 | 持续学习 | 是否知道下一步如何深化？（延伸阅读、进阶边界） |

**评分**：每维 1-5（1 严重缺失 / 2 显著不足 / 3 基本达标 / 4 良好 / 5 标杆）。只评**有证据**的维度。

**十六→五维度的整合**（五维度评分 = 相关十六维度综合 + 质性判断，非机械平均）：
- 读者旅程 ← C1 + B4 + D1　·　首次成功 ← D2 + C1 + B1　·　错误恢复 ← D3 + A1 + C3
- 参考可用性 ← D4 + A2 + A4　·　动机有效性 ← D5 + B2 + D1
- **质性规则**：某构成维度 ≤2 时，该五维度上限为 3——防机械平均掩盖严重缺陷。参考可用性评分须含 3-5 个真实检索任务（目标/入口/找到位置/失败原因）。

## 输出模板

| 模式 | 评分范围 | 重点 | 省略 |
|---|---|---|---|
| 深度 | 完整十六 + 五维度 | 新书全面评估、出版级改造 | 无 |
| 标准 | 有证据的风险维度 + 五维度 | 目标读者、学习路径、核心技术风险、系统性残留、修复批次 | 无证据维度的逐项评分 |
| 快速 | 四层面一句话结论 | 已知问题复查、回归确认 | 完整评分表、五维度权重 |

评分表服务决策不服务填表：无证据不强行评分，同类低层问题合并为系统性发现。

### 报告结构（标准/深度模式）

```markdown
# 《书名》技术审阅报告
## 总评            [一段：适合谁、核心优势、最大问题、推荐度]
## 目标读者与学习路径   [读者假设 / 学习路径图摘要 / 主要断点]
## 评分总览          [十六维度表（标准模式只列有证据的）+ 五维度表]
## 核心发现          [优势 Top3 / 问题 Top3]
## 逐章详细审阅       [ChN: 评分 A/B/C/D + 优势 + 问题 + 建议]
## 系统性问题        [跨章模式性问题，对照 review-criteria 反模式]
## 改进建议          [高/中/低优先级]
## 修复批次          [P0 技术错误 / P1 结构 / P2 风格翻译 / P3 参考体验]
```

快速模式：总评 + 关键发现（优势/问题各 3）+ 四层面一句话评分（基础质量/阅读体验/教学设计/读者转化）+ 最优先改进。

## 校验清单

- [ ] 每个评分有具体证据（非"感觉"）；技术准确性至少验证 3 个代码示例；覆盖度对照官方主题清单
- [ ] 问题建议可操作（"在 Ch3 第 2 节加 X"而非"加强 XX"）
- [ ] 反模式清单检查了全部 4 类；五维度与十六维度关系自洽
- [ ] 问题归属分类完成（翻译/整合/审阅三类分开）；改进按优先级排列
